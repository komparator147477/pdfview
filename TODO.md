# Follow-ups

## Text workflow

- [ ] Search text in a PDF: next/previous match and visible highlighting.
- [ ] Select text and copy it.
- [ ] Make quick corrections to existing text: edit or remove selected text.
- [ ] Add text and images, including a new blank PDF with a short note, a picture,
  or both on one page.
- [ ] Basic text formatting: font, size, alignment and positioning. Consider
  opening a text block in Vim/Neovim if it makes editing simpler.

Keep this focused on quick PDF tasks. A Word/Acrobat replacement or a DOCX export
workflow is outside the intended scope.
